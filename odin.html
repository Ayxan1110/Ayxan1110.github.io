The Odin Project

The Odin Project is a free, open source curriculum for web development. Instead of watching videos, you read lessons, do exercises and build real projects. In the Web Technologies class we follow the Full Stack JavaScript path. For every course below you can find what it is about, my presentation, my screen recording and the projects I built.
